# Packet28 v0.2.45

## Summary

This release introduces the first cross-platform Packet28 runtime contract so Linux preload interception, future filesystem overlays, and future proxy backends can all share one daemon decision engine.

## Highlights

- Added a backend-agnostic `ContextResolve` daemon API and kept `InstructionFileResolve` as a compatibility shim over the new contract.
- Added the `packet28.instruction.summarize` reducer and runtime metadata so summaries now carry source kind, backend kind, and agent family context.
- Added `Packet28 run` as the new runtime launcher surface, with Linux preload wired in today and explicit stubs for Linux OCI, macOS FUSE, Windows FUSE, and proxy-only backends.
- Added the `context-instruct-shim` workspace crate, including the validated Linux preload path and the experimental macOS interpose path used for feasibility testing.
