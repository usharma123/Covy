# Packet28 v0.2.42

## Summary

This release hardens Packet28's Rust workspace by making the codebase pass strict `clippy` checks under the declared MSRV without changing the release workflow.

## Highlights

- Cleaned up shared crates, reducer code, search core, and packet structures to satisfy workspace-wide `clippy -D warnings`.
- Simplified `p28`, `packet28d`, and `suite-cli` helper code to remove MSRV-incompatible patterns, oversized helper signatures, and test lifecycle issues.
- Kept the full workspace green with strict linting and test verification before cutting the release.

## Verification

- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`
