# Packet28 v0.2.44

## Summary

This release trims the native MCP search slim payload so Packet28 keeps the most useful in-turn navigation hints while cutting duplicated summary and metadata output.

## Highlights

- Reworked the native `packet28.search` slim response to use a one-line summary preview instead of repeating the same file list already exposed through navigation fields.
- Reduced slim payload caps for search paths, regions, and symbols so common search results stay compact without losing artifact-backed drill-down paths.
- Kept backend and hybrid execution metadata available in slim mode, but made those objects sparse so they preserve debugging value without dragging benchmark token counts.
