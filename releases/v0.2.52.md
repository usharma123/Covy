# Packet28 v0.2.52

## Summary

This release makes Packet28 setup match modern one-command `npx` setup flows: running `npx packet28@latest` now opens the setup wizard directly, while `npx packet28@latest setup --runtime all --yes` remains the scripted install path.

## Highlights

- Defaulted a bare `Packet28` invocation to the interactive setup wizard.
- Kept explicit subcommands, daemon routing, and machine-readable error handling intact after making the top-level command optional.
- Updated quick-start and product docs to present the one-command wizard first.
- Added npm launcher support for `PACKET28_BINARY` so release smoke tests can exercise a freshly built local binary even when cached optional dependency binaries are present.
- Cleaned up stale Claude Code Packet28 command hooks when setup installs the newer HTTP hook integration.
