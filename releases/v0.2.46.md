# Packet28 v0.2.46

## Summary

This release hardens Packet28's search reducer so it can still answer regex-style searches when `rg` is unavailable, instead of failing over to a grep path that misses some anchored patterns.

## Highlights

- Added a reducer-core fallback matcher that walks files directly when `rg` is missing.
- Preserved fixed-string, whole-word, case-sensitivity, and per-file match limit behavior in the fallback path.
- Added regression coverage for anchored line-start regex searches so the fallback behavior is validated explicitly.

## Verification

- `cargo test -p packet28-reducer-core -- --nocapture`
