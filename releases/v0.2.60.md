# Packet28 v0.2.60

## Summary

This release hardens CI and release-readiness checks after the experiment
manifest workflow exposed ignored local artifact references.

## Fixes

- Repointed experiment manifest evidence to committed summaries instead of
  ignored generated run directories.
- Added a manifest artifact guard so CI fails when experiment evidence is
  missing, ignored, or untracked in a fresh checkout.
- Updated GitHub Actions workflow dependencies to Node 24-compatible major
  versions ahead of the GitHub Actions Node 20 cutoff.
- Aligned Cargo and npm source package metadata to v0.2.60 for the release tag.
