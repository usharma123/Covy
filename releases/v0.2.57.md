# Packet28 v0.2.57

## Summary

This stability patch fixes MCP startup failures caused by packaged `packet28d` binaries that are present beside `Packet28` but lack execute permissions.

## Fixes

- Repair non-executable `packet28d` permissions in the Rust daemon launcher before spawning the daemon.
- Repair the `packet28d` sibling from both `packet28` and `packet28-mcp` npm entrypoints, even when the main `Packet28` binary is already executable.
- Document the confirmed permission bug in `bug.md`.

## Verification

- `cargo fmt`
- `cargo test -p suite-cli ensure_executable_repairs_packaged_daemon_mode`
- `cargo check -p suite-cli -p packet28d -p packet28-daemon-core`
- `cargo build -p suite-cli -p packet28d`
