# Packet28 v0.2.48

## Summary

This release adds the Phase A macOS `macos-swap` runtime backend so `Packet28 run` can rewrite repo-root instruction files before launching CLI agents, then restore the originals on exit or the next launch after a crash.

## Highlights

- Added `macos-swap` as the macOS `Packet28 run --backend auto` path.
- Reused the existing `ContextResolve` daemon contract for repo-root `AGENTS.md`, `AGENTS.MD`, and `CLAUDE.md` rewrites.
- Added session reports and stale-session recovery under `.packet28/runtime/macos-swap`.
- Restored original instruction files after normal exit, signal exit, and next-launch recovery.
- Validated the path against real `claude` CLI launches on macOS.
