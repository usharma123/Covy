# Packet28 v0.2.47

## Summary

This release fixes the tag-triggered release workflow so Linux musl packaging only builds the shipped binaries, avoiding the musl-incompatible `context-instruct-shim` cdylib.

## Highlights

- Narrowed the release build matrix commands to `Packet28` and `packet28d` instead of the full workspace.
- Prevented the Linux musl release job from trying to build the `context-instruct-shim` `cdylib`.
- Ignored local `.txt` transcript files so ad hoc notes do not pollute the repo status during release work.

## Verification

- `cargo check -p suite-cli -p packet28d`
