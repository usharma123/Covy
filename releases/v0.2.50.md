# Packet28 v0.2.50

## Summary

This release ships `p28` as a first-class installed command in the npm and tag-release flow, and updates generated agent guidance to prefer `p28` for search while keeping Packet28 MCP focused on read/list and handoff tasks.

## Highlights

- Added `p28` to the tag-triggered release workflow and npm package wrappers so `npm install -g packet28` installs `p28`, `packet28`, and `packet28-mcp`.
- Updated generated agent prompt fragments and smoke coverage so setup-written instruction files prefer `p28` instant grep instead of steering agents toward `packet28.search`.
- Kept Packet28 MCP available for compact `read_regions`, `glob`, artifact fetch, and handoff workflows without making MCP search the default guidance path.

## Verification

- `cargo test -q -p suite-cli agent_surface -- --nocapture`
- `cargo test -q -p suite-cli test_suite_agent_prompt_outputs_all_supported_fragments -- --exact`
