# Packet28 v0.2.41

## Summary

This release improves Packet28's MCP search surface and hook transport.

## Highlights

- Added hybrid `packet28.search` behavior so the MCP tool can combine indexed search with native recall verification while still returning a compact slim payload.
- Expanded slim `packet28.search` responses to include navigation-ready `paths`, `regions`, `symbols`, diagnostics, engine metadata, and hybrid execution details.
- Added persistent Claude HTTP hook transport support.
