# Packet28 v0.2.49

## Summary

This release fixes a cross-platform compile bug in the new `macos-swap` runtime backend so Linux CI and release builds can compile `suite-cli` again.

## Highlights

- Made `anyhow::{anyhow, Result}` available to the non-macOS fallback in `cmd_macos_swap.rs`.
- Preserved the macOS-only `Context` import while fixing Linux and musl builds.
- Unblocked both the Hook Benchmark Suite and the tag-triggered Release workflow.

## Verification

- `cargo check -p suite-cli -p packet28d -p packet28-daemon-core`
- `cargo build -p suite-cli -p packet28d -p packet28-reducer-core`
