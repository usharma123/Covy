# Packet28 v0.2.64

This release makes Claude Code hook setup portable, self-starting, and directly verifiable for new installations.

## Highlights

- Generate Claude hook commands with `${CLAUDE_PROJECT_DIR}` so repositories remain valid after cloning or moving.
- Keep repository-local MCP roots relative while preserving absolute roots for user-scoped clients such as Windsurf.
- Align generated Claude hook matchers with the current Claude Code hook schema, including `fork` session starts and matcher-free `Stop` and `UserPromptSubmit` events.
- Start and health-check the Packet28 HTTP hook service during setup instead of reporting success with an unavailable listener.
- Extend `Packet28 doctor --agent claude` to validate the installed hook configuration, token, URL allowlist, and live HTTP service.
- Add regression coverage for portable roots, current matcher semantics, service health, and user-scoped MCP configuration.

## Evidence

- Pull request #34 passed the canonical all-target/all-feature quality gate, exact MSRV gate, hook benchmark, experiment manifest, and integration checks.
- Fresh-workspace Claude setup and doctor verification passed with a live hook endpoint rooted to the temporary repository.
- A live Claude Code hook smoke exercised `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, and `Stop`, including Packet28 command rewriting.
- Focused Claude, Cursor, and Windsurf setup, MCP smoke, and doctor regressions passed locally and in CI.
