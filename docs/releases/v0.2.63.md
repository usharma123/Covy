# Packet28 v0.2.63

This release completes a broad codebase-health refactor while hardening Packet28's daemon-managed hook and indexed-search paths.

## Highlights

- Split large command, daemon, MCP, routing, dashboard, setup, memory, and test-support modules into focused boundaries without changing their public behavior.
- Fixed daemon stop so it does not auto-start an absent daemon.
- Fixed daemon-managed Claude relaunches so the daemon invokes `claude --continue` directly instead of nesting a second handoff waiter.
- Hardened reducer cache invalidation for out-of-band workspace mutations.
- Preserved grep basic-regex semantics in compact hook rewrites, including escaped alternation.
- Removed dead MCP state code and an unused policy dependency.
- Refreshed the architecture boundary and retained-fallback documentation.
